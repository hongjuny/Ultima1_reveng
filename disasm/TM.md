# TM — time machine and finale

Overlay range: `$8956–$A910`; entry `$8956`.

Visible text describes a time-machine sequence and Mondain confrontation. The controlled route into this module, its main loop, gem action, directional attack, and ending gate have now been traced. The full naturally acquired four-gem route and `NIF` structure remain open.

The main cycle starts at `$8E5E`: it resets the stack, prints a control sequence, then `$8E67` runs local `$9844` and common display `$836E`. A zero HP/food gate jumps to shared `$88F8`; otherwise `$9815` handles input and returns a key. The [40-byte dispatch](TM-command-dispatch.s) at `$8E80–$8EA7` reassembles exactly: it handles the zero-key path locally, passes a nonzero key to common `$82A2`, patches a handler call from the local table `$8EA8`, calls `$8414`, and jumps back to `$8E5E`. `$9815` uses `$15C8` and `$15BF` through `$9827`, unlike the direct `$15C2` polls in several other overlays.

Controlled selection with A=`$18` loaded all 8,123 TM bytes at `$8956`. An initial probe injected PC=`$8E5E` after loading and reached `$9815`, showing that the candidate loop was executable. The full opening sequence has since been replayed; see below.

The controlled OUT B-command transition reaches the real TM entry `$8AD7`. Four shared page prompts at `$87F7 → $881B` each accept Space with A=`$20` at `$881E`, then reach the natural `$8E5E → $9815` main loop. A further Space command decodes to X=`$08`, calls handler `$9801` through the patched `$8E9F`, and returns to the next `$9815`. The source snapshots and replays are described in [turn contracts](../docs/turn-contracts.md).

From that controlled entry, ten East inputs moved the player `(4,5)→(14,5)` through `$96C4`. The last move reduced player HP `150→109`; Mondain remained at 1000 HP. `G` then dispatched to `$94D6`, set `$95AB:0→1` at `$951A`, and returned to input with player HP 28 and Mondain at `(15,5)`. The HP loss is measured at input boundaries; the exact damage substeps have not been isolated. The [private trace verifier](../tools/verify_tm_victory_gate.py) checks every move, handler, state, and snapshot link.

`A` calls `$8EDC`, which asks for a direction through `$916F→$9815`. With East as the second key, the adjacent target was hit at `$8F80` and Mondain HP fell `1000→970`. `$8FEE` handles lethal damage, marks phase `$7EF2=$FF`, and checks `$95AB` at `$901D`. A controlled replay changed only Mondain HP from 1000 to 1 before the same two keys. With the destroyed-gem flag retained, the branch reached victory `$9034`; changing that flag to zero in a separate control reached `$9033` instead. From `$9034`, execution requested `NIF` at `$9052→$B703`, returned at `$9059`, and the full 7680 bytes at `$4000` matched the extracted file. These controls prove the gate and load path, not an uninterrupted 1000-HP battle or full ending display.

After the load, `$9073–$9093` moved **8192** bytes `$4000–$5FFF → $6000–$7FFF` exactly and cleared the source range to zero. The `NIF` file supplies the first 7680 bytes; the last 512 come from preexisting `$5E00–$5FFF` RAM, with 232 nonzero bytes in this run. The move overwrites the normal `$7E00` game state region as the ending begins. Execution reached animation `$90AA`, then final keyboard wait `$9132`. Space led to `$914D → $912F`, returning to that wait. The source and destination ranges, overread count, clearing, and key loop are checked by the same [verifier](../tools/verify_tm_victory_gate.py). The origin and visual use of the extra 512 bytes need further study.

The 512-byte tail had the same contents at TM's first command and immediately after `NIF` load, so the loader left that region untouched. Under the emulator's HGR row-address mapping, 480 of these 512 positions correspond to pixel bytes and all 232 nonzero tail bytes lie in those positions. `$6000` is an animation buffer rather than a directly displayed HGR page; tracing which tail bytes the animation copies to the visible pages remains necessary.

A paired controlled replay cleared only `$5E00–$5FFF` at the `NIF` loader return. At copy completion `$9094`, animation entry `$90AA`, and final key wait `$9132`, the `$6000` buffer differed in exactly 232 bytes while both display page regions `$2000–$3FFF` and `$4000–$5FFF` were byte-identical. Thus the inherited tail does not change either video page at these sampled points; intermediate animation frames and alternate entry states remain untested.

The [NIF render trace](../tools/trace_tm_nif_render.py) resolves why this tail is absent from the displayed ending: the animation consumes 192 packed rows of 40 bytes from `$6000–$7DFF`, stopping with source pointer `$7E00`. The first row goes to HGR page 2 bottom-row address `$5FD0`, and the final HGR page 1 matches all 7,680 `NIF` bytes by scanline address. [NIF format and local extractor](NIF.md) document the exact file-to-frame transformation. Intermediate frame timing and page selection still need a visual differential test.

## Mondain combat phases

The first ordinary A/East hit reduced Mondain HP `1000→970`; at the next TM input the player had lost `28→10` HP. A second A/East missed (`$8F73`) and the next input had player HP `5`, Mondain HP `970`. The retaliation at `$99BF–$99E6` computes `floor(current player HP / 32) + random(0..19)` and subtracts it through `$9B15`. This formula matches both ordinary hits and all 36 phase-one retaliation turns in the controlled run below.

The [retaliation damage fragment](TM-retaliation-damage.s), [flee/regeneration fragment](TM-flee-regeneration.s), and [flee movement fragment](TM-flee-movement.s) reassemble byte-for-byte against the local TM extraction. The movement routine `$9936–$9970` randomly chooses which axis to try first, tests candidate cells through `$9D98/$9D74`, commits a free cell with carry clear, or returns carry set when both attempts fail. This carry controls the 5-HP regeneration branch.

To observe the full 1000-HP first phase without changing Mondain, a replay raised only player HP `$7EC6/$7EC7` from 28 to 10000 at the post-G input. The first 37 A/East attacks reduced Mondain HP `1000→482`, including misses. On attack 37, the `$8FC8–$8FED` threshold selected phase `$7EF2:1→2` when HP fell below 500. In phase 2, `$98E3–$98FF` reverses the desired movement direction away from the player; `$9900–$9934` adds 5 HP when movement is blocked and returns to phase 1 upon reaching 500. In the replay Mondain moved `(15,5)→(16,5)`, later regenerated `482→487`, and one follow-up hit lowered him `487→484` before he fled again. The [phase verifier](../tools/verify_tm_phase_transition.py) checks 43 turns, state continuity, exact intervention, thresholds, and damage bounds. A sustained natural fight through phase 2 and the best player strategy remain open.

A paired replay from the same blocked-move input changed only Mondain HP `482→495`. The ordinary Up move yielded `482→487`, phase 2; the controlled Up move yielded `495→500`, phase `2→1`, with identical player and Mondain positions. This directly confirms the regeneration threshold without replacing the whole battle.

Continuing the 43-turn controlled fight with ordinary Space inputs, Mondain fled from `(15,3)` to the `(1,1)` corner over 16 turns. Four blocked flee attempts there raised his HP `484→489→494→499→504`; the fourth changed phase `2→1`. Player HP stayed 2997. During 80 further Space turns Mondain pursued to `(11,4)` by turn 15, then remained there while player stayed `(16,4)`. Player HP fell `2997→2177` during those waits, with Mondain HP fixed at 504. The phase-one dispatch at `$98BF–$98E2` selects close attack, movement, or the distant branch `$99E7` according to a distance calculation and a random draw. A further nine-Space replay from the blocked position hit `$99E7` on turns 3, 4, 5, 7, and 9; the last hit reduced player HP `2177→2164`. The branch's internal effect distribution remains to be characterized.

From the same 80-turn input snapshot, six ordinary movement keys routed the player around the wall to `(11,5)` while Mondain remained `(11,4)`; player HP fell `2177→2005`. `A`, then Up, hit Mondain `504→492`, changed phase `1→2`, and he fled to `(11,3)`. Thus a single controlled player-HP increase before the fight supports a replayed `1→2→1→2` combat cycle with no later RAM edits. The [phase-cycle verifier](../tools/verify_tm_phase_cycle.py) checks both Space runs, the distant-branch replay, the seven re-engagement actions, snapshot ancestry, and final memory. Victory by repeated ordinary attacks remains untraced.

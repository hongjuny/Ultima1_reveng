# U1.SYSTEM

Load range: `$2000–$2691`. ProDOS SYS startup file.

| Address | Disassembly / evidence | Interpretation |
| --- | --- | --- |
| `$2000` | `JMP $2088` | Startup entry |
| `$2007` | `U1.INTRO` string in startup header | Next program name |
| `$2088` | `SEI`; initializes ProDOS/display state and stack | Startup routine; exact handoff pending |
| `$21A6–$21AA` | `LDY $2006; BNE $21D6` | Tests the startup filename length byte (8 in the extracted file) |
| `$21B4–$21D5` | `JSR $0100`; inline `Can't find a startup file.` text; `JMP $0133` at `$21D3` | Path taken when `$2006` is zero; runtime cause pending |
| `$2220` | `JMP $0136` | Transfers through a low-memory entry; target semantics pending |

Code and inline display text are interleaved after `$2088`; the linear draft treats text as instructions. Earlier trace timeouts at PC `$21D4` cannot be mapped to this file: the source snapshot contained ProDOS bytes at `$2088`, so execution was still in ProDOS. The no-startup-file path is identified from extracted bytes only. A new trace must first verify the loaded `U1.SYSTEM` image in memory.
